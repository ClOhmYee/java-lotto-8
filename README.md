# java-lotto-precourse

프리코스 3주차 과제

## 기능 구현 상세

---

**1. Lotto 클래스 구현**

    로또 데이터를 관리하는 클래스

**2. LottoGenerator 클래스 구현**

    로또 데이터를 생성하는 클래스

**3. LottoStandard enum 정의**

    로또 당첨 기준과 금액을 정한 열거형

**4. LottoWinning 클래스 구현**

    당첨 번호를 관리하는 클래스

**5. LottoCheck 클래스 구현**

    하나의 로또 데이터와 당첨 데이터를 비교해 상금을 파악하는 클래스

**6. LottoResult 클래스 구현**

    주어진 조건에서 구입한 모든 로또 데이터를 바탕으로 총 수익을 계산하는 클래스

**7. InputView 클래스 구현**

    사용자에게서 데이터를 받는 클래스

**8. OutputView 클래스 구현**

    로또 당첨 결과를 출력하는 클래스

**9. Application 클래스 최종 구현**

    주어진 조건에 맞게 기능을 활용하는 main 클래스
